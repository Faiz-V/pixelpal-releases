# Product media checklist

No current-version desktop screenshot or GIF is bundled yet. Add authentic captures only, with platform, app version, capture date and a short caption. Do not use generated mockups as product evidence.

Suggested structure when media is available:

- `screenshots/windows-v2.3.0/`: desktop companion, Workstation, Agent Activity and Pal FM.
- `screenshots/macos-v2.0.0/`: separately verified macOS views, explicitly labeled Previous Stable.
- `demos/`: a short recorded Windows workflow showing a request, confirmation where needed, visible progress and the actual result.

Do not publish API keys, account identifiers, private documents, personal filenames or private prompts. Confirm the rights to any included artwork, voices and music. Older approved screenshots may be labeled as archive captures; do not relabel them as current-version evidence.
